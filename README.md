# Minuto 90

Web de análisis de datos del Real Madrid: **https://aluse33.github.io/madrid-analytics/**

Proyecto personal de [Alejandro Lucas](https://aluse33.github.io/), economista y doctorando especializado en econometría e inferencia causal.

## Qué hay

- **Descriptivos**: resultados y xG partido a partido, alineaciones y cronología de cada partido, mapas de tiros, fichas de jugador, Champions League e histórico del club.
- **Modelos**: predicción de partidos (Dixon-Coles), simulación Monte Carlo de la Liga, estimaciones empírico-bayesianas por jugador y un modelo de xG propio.

Los datos se actualizan solos cada mañana. Salen de Understat, ESPN y Wikipedia; en el repositorio solo se publican los resultados de los modelos, no los datos originales.

Está hecho en Python (datos y modelos) y [Observable Framework](https://observablehq.com/framework/) (web), y se publica con GitHub Actions y GitHub Pages.

> Proyecto en desarrollo: puede haber errores, y los modelos todavía necesitan trabajo. Sin relación con el Real Madrid C.F.
